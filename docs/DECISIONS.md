# Decisions

Format: Decision / Reason / Tradeoff. Newest at the bottom. Started 2026-10-03.

## D1. Build a new app instead of extending one
- **Decision:** New app, Patina. Reuse patterns, not codebases.
- **Reason:** The project assessment (`docs/assessment/`) found no domain fit. DYT is the most mature but is a hockey league; FieldCheck is a benchmark with one attachment and no findings, queue, map or timeline; Plinth (closest domain) has no screens.
- **Tradeoff:** No inherited code paths, so every screen is new work. Proven pieces are copied with attribution: FieldCheck attachment storage pattern, MorningCard `MutedTileSource`, ChefsNobu Mapsui setup, ZooQuest store pattern.

## D2. Concept: public-art conservation for a municipal team
- **Decision:** Field app for a city's public-art conservation unit (conservators and technicians) that keeps outdoor works (bronze, steel, stone, murals, mosaic) in condition.
- **Reason:** Matches the concept rule (credible industry, specific team, distinctive workflow) and exercises photos, map, history, gates and offline use. Bilingual EN/FR fits a Montréal team.
- **Tradeoff:** Collection data is fictional, so no artwork photos ship with the app. Artworks without a photo show an honest empty state that invites the first survey photo.

## D3. Release scope: single device, local-first
- **Decision:** v1 keeps all data on the device (JSON document + photo files in `ApplicationData.LocalFolder`). Export and import of the whole record as a `.patina.json` file is the hand-off between devices.
- **Reason:** No backend, credentials or tenancy exist for this release. Local-first works offline in the field, which the job needs anyway.
- **Tradeoff:** No live multi-user sync or sign-in. Listed in Unresolved Questions with the DYT Supabase pattern as the candidate.

## D4. Uno.Sdk 6.7.30, .NET 10, single project + core library
- **Decision:** `Patina` (Uno single project) + `Patina.Core` (plain `net10.0`: domain, rules, store) + `Patina.Tests` (MSTest on Core).
- **Reason:** 6.7.30 is the latest stable (NuGet, 2026-10-03). Keeping the domain in plain .NET makes the rules testable without a UI head (DYT's Core split).
- **Tradeoff:** One extra project boundary; Core cannot touch WinRT storage, so the app supplies a file-system adapter.

## D5. MVUX + Navigation Extensions + Toolkit + Material
- **Decision:** MVUX models, region navigation, Uno Toolkit controls, Material theme generated by DesignMd2Uno.
- **Reason:** Project convention: MVUX for async app state (`uno-scaffolding.md`). Material because the generated role palette and type ramp come from DesignMd2Uno, which emits Material resources.
- **Tradeoff:** `{Binding}` only on MVUX pages (no `x:Bind` against generated view models).

## D6. Targets
- **Decision:** `net10.0-desktop` (Windows, macOS, Linux via Skia), `net10.0-browserwasm` (PWA), `net10.0-android`, `net10.0-ios`. No WinAppSDK head.
- **Reason:** The Skia desktop head covers three OSes with one renderer. The WinAppSDK head adds a second renderer with known layout differences (FieldCheck VSM gotcha) and no capability Patina needs.
- **Tradeoff:** No MSIX store packaging. Can build/test here: Windows desktop, WASM, Android (API 36 emulator), Linux desktop via WSL. Cannot build here: iOS (needs a Mac), macOS (desktop head builds but cannot be run here).

## D7. Map: Mapsui 5.1.0 with muted OSM tiles
- **Decision:** `Mapsui.Uno.WinUI` 5.1.0, OSM tiles with an identifying User-Agent, tinted toward the canvas with MorningCard's `MutedTileSource`.
- **Reason:** Validated on desktop and Android with Uno.Sdk 6.7.30 (runtime gotchas). Uno's MapControl has no desktop support.
- **Tradeoff:** Public OSM tiles are a policy dependency. WASM rendering is unverified (Risk).

## D8. Photos: picker everywhere, camera on mobile
- **Decision:** `CameraCaptureUI` on Android/iOS, `FileOpenPicker` on every head. Files are copied into `LocalFolder/photos`.
- **Reason:** Uno docs: CameraCaptureUI is Android/iOS/WinUI only and returns null elsewhere; FileOpenPicker is supported on all heads.
- **Tradeoff:** Desktop and web users attach photos from disk.

## D9. Motion values from `xaml-design-polish`, not the MotionTokens library
- **Decision:** House values: 150/200/280 ms, EaseSmooth `0.22,1 0.36,1`, press 0.98, gated on `UISettings.AnimationsEnabled`.
- **Reason:** The two disagree (MotionTokens uses 100–600 ms and `0.2,0,0,1`); the skill is authoritative in this setup.
- **Tradeoff:** The MotionTokens library is not consumed. Its open conflict stays open (`Motiontokens/docs/DECISIONS.md` §2–3).

## D10. Theme from DESIGN.md via DesignMd2Uno
- **Decision:** `docs/DESIGN.md` is the source. `Styles/ColorPaletteOverride.xaml`, `Typography.xaml`, `Tokens.xaml` are generated and never hand-edited.
- **Reason:** One owner per layer. The generator also checks contrast (24/24 pairs pass 4.5:1 on first run).
- **Tradeoff:** Regenerating requires the private DesignMd2Uno repo.

## D11. Breakpoints on cached pages use AdaptiveTrigger (workaround)
- **Decision:** `MainPage`, `CollectionPage`, `SettingsPage` use `AdaptiveTrigger` states; everything else keeps `{utu:Responsive}`.
- **Reason:** Toolkit 9.1 `ResponsiveExtension` never reconnects after its host unloads (source-read; `KNOWN-ISSUES.md`). These pages are cached and unload when a detail page opens.
- **Tradeoff:** two breakpoint mechanisms in one app, each workaround marked and greppable. Revert when the Toolkit fixes reconnect.

## D12. Display strings from ResourceLoader
- **Decision:** converters and models read `.resw` through `ResourceLoader` (`Services/Text.cs`), the same files as `x:Uid`.
- **Reason:** navigation constructs models before the host's `IStringLocalizer` is reachable from static code; the first attempt rendered raw keys.
- **Tradeoff:** a static helper instead of injected localization in converters.

## D13. Index-based selection for ComboBox and RadioButtons
- **Decision:** survey weather, finding type and severity bind `SelectedIndex` to `int` fields of the form records.
- **Reason:** record `SelectedItem` values did not round-trip through the MVUX bindable proxy (empty selection at runtime).
- **Tradeoff:** the model maps indexes back to options.

## D14. Portable entrance animation
- **Decision:** page entrances are a Storyboard (opacity + `TranslateTransform`, EaseSmooth spline, 280 ms).
- **Reason:** `ElementCompositionPreview.SetIsTranslationEnabled` is Uno0001 on WebAssembly; the Uno0001-as-error policy caught it.
- **Tradeoff:** UI-thread animation instead of Composition; two properties on one element per page, measured smooth.

## D15. Export format is a zip
- **Decision:** `.patina` = zip of `collection.json` (versioned envelope) + `photos/`.
- **Reason:** a collection moved without its photos loses its documentation.
- **Tradeoff:** larger files; import extracts only photos the document references.
